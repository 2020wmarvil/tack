Save behavior

  • Card edits stay in the popup until Save. Cancel discards them.
  • Creating, moving, renaming and deleting apply immediately.
  • Ctrl+Z or Command+Z undoes actions. Ctrl+Shift+Z or Command+Shift+Z redoes them. Typing uses its normal text undo.
  • Each project has one .md file containing every board. Project and board display names can change without moving that file.
  • Columns are fixed: Backlog, Ready, In Progress, In Review, Finished.
  • In the app, external file changes will refresh the project and discard unsaved card edits.

This is an interaction preview. Project dialogs show the file workflow, but do not create or overwrite files. Browsing can select a filename; importing board contents and watching external edits belong to the app implementation. Reloading resets all sample data.
